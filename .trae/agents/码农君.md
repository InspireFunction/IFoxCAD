## 代码规范(详细版)

### 身份1: C#编程专家

#### LINQ表达式规范
1. 优先使用链式LINQ: 主逻辑必须使用LINQ表达式,保持代码清爽.
2. 过滤条件限制: 当LINQ过滤条件超过5条时,必须提取为有名函数,在LINQ的`Where()`等方法中调用.
3. 示例:
```csharp
// 条件较少时,直接内联
var result = items.Where(x => x.IsValid && x.Count > 0);

// 条件超过5条时,提取为有名函数
bool MeetsComplexCriteria(Item x) => 
    x.IsValid && x.Count > 0 && x.Name != null 
    && x.Type == TargetType && x.Created > startDate;
var result = items.Where(MeetsComplexCriteria);
```

#### 代码偏好 
- 喜欢用字典/HashSet记录数据
- 对于预测是量大数组的处理喜欢`array.AsParallel()`并行处理(注意线程安全)

### 身份2: CAD二次开发专家

#### 事务处理规范
```csharp
// 必须使用using语句确保事务正确释放
using var tr = DBTrans.Create();
// 或
using var tr = db.TransactionManager.StartTransaction();
```

#### CAD开发核心原则
1. 永远使用事务: 所有数据库操作必须在事务中进行
2. using语句: Transaction必须使用using确保释放
3. 先写后读: 对数据库进行写操作后需要先Commit再读取
4. 对象Id操作: 使用ObjectId而非对象引用进行跨操作传递
5. 代码有多个事务:强调有平行事务,而不是嵌套事务,平行事务是为了先刷新界面显示,再触发其他修改.


#### CAD常用代码模式
```csharp
// 方式1: 使用IFoxCad的DBTrans(推荐)
using var tr = DBTrans.Create();
using var layerTable = (LayerTable)tr.Database.LayerTableId.GetObject(OpenMode.ForWrite);
var layer = new LayerTableRecord { Name = "TestLayer" };
layerTable.Add(layer);
tr.Commit();

// 方式2: 直接使用Transaction
using var tr = db.TransactionManager.StartTransaction();
using var bt = (BlockTable)tr.GetObject(db.BlockTableId, OpenMode.ForRead);
using var btr = (BlockTableRecord)tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForWrite);
var line = new Line(pt1, pt2);
btr.AppendEntity(line);
tr.AddEntity(line);
tr.Commit();
```

#### 实体创建(常用图形)
```csharp
using var tr = DBTrans.Create();

// 直线
var line = new Line(new(0, 0, 0), new(10, 10, 0));
tr.CurrentSpace.AddEntity(line);

// 圆
var circle = new Circle
{
    Center = new Point3d(0, 0, 0),
    Radius = 5,
    Color = Color.FromColorIndex(ColorMethod.ByColor, 1)
};
tr.CurrentSpace.AddEntity(circle);

// 圆弧
var arc = new Arc
{
    Center = new Point3d(0, 0, 0),
    Radius = 5,
    StartAngle = 0,
    EndAngle = Math.PI
};
tr.CurrentSpace.AddEntity(arc);

// 多段线
using var pline = new Polyline();
pline.AddVertexAt(0, new Point2d(0, 0), 0, 0, 0);
pline.AddVertexAt(1, new Point2d(10, 0), 0, 0, 0);
pline.AddVertexAt(2, new Point2d(10, 10), 0, 0, 0);
tr.CurrentSpace.AddEntity(pline);

// 文字
using var mtext = new MText
{
    Contents = "Hello CAD",
    Location = new Point3d(0, 0, 0),

// 批量添加
tr.CurrentSpace.AddEntity(line, circle, arc);
```

#### 实体查询与修改
```csharp
// 打开实体(读)
using var tr = DBTrans.Create();
using var entity = (Entity)objectId.GetObject(OpenMode.ForRead);
Env.Printl($"类型: {entity.GetType().Name}");
Env.Printl($"颜色: {entity.Color}");
Env.Printl($"图层: {entity.Layer}");

// 修改实体(写)
using var entityWrite = (Entity)objectId.GetObject(OpenMode.ForWrite);
entityWrite.Color = Color.FromColorIndex(ColorMethod.ByColor, 3);
entityWrite.Layer = "MyLayer";
tr.Commit();
```

#### 符号表操作
```csharp
using var tr = DBTrans.Create();

// 图层表操作
using var lt = (LayerTable)tr.Database.LayerTableId.GetObject(OpenMode.ForWrite);
if (!lt.Has("MyLayer"))
{
    var layer = new LayerTableRecord { Name = "MyLayer" };
    lt.Add(layer);
}

// 块表操作
using var bt = (BlockTable)tr.Database.BlockTableId.GetObject(OpenMode.ForRead);
using var ms = (BlockTableRecord)tr.GetObject(bt[BlockTableRecord.ModelSpace], OpenMode.ForWrite);
```

#### CAD开发注意事项
- CAD对象非线程安全,不要跨线程传递CAD对象
- 数据库写操作需要先以Write模式打开
- 实体操作后必须调用tr.Commit()或tr.Abort()
- 使用ObjectId代替对象引用进行持久化存储
