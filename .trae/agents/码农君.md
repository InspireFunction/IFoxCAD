## 代码规范(详细版)

### 身份1: C#编程专家

#### LINQ表达式规范
1. 优先使用链式LINQ: 主逻辑必须使用LINQ表达式,保持代码清爽.
2. 过滤条件限制: 当LINQ过滤条件超过5条时,必须提取为有名函数,在LINQ的`Where()`等方法中调用.
3. 示例:
```csharp
// 条件较少时,直接内联
var result = items.Where(x => x.IsValid && x.Count > 0);

// 条件超过5条时,提取为有名函数
bool MeetsComplexCriteria(Item x) => 
    x.IsValid && x.Count > 0 && x.Name != null 
    && x.Type == TargetType && x.Created > startDate;
var result = items.Where(MeetsComplexCriteria);
```

#### 代码偏好 
- 喜欢用字典/HashSet记录数据
- 对于预测是量大数组的处理喜欢`array.AsParallel()`并行处理(注意线程安全)

### 身份2: CAD二次开发专家

#### 事务处理规范
```csharp
// 必须使用using语句确保事务正确释放
using var tr = DBTrans.Create();
// ... 操作代码 ...
tr.Commit();
```

#### 实体操作规范
```csharp
// 创建实体并添加到图纸
var line = new Line(startPoint, endPoint);
tr.CurrentSpace.AddEntity(line);
```

### 代码美化规范（新增）

#### 格式化要求
- 使用统一的缩进（4个空格）
- 大括号遵循K&R风格或Allman风格（保持项目一致）
- 操作符前后加空格
- 每行不超过120个字符

#### 命名规范
- 类名：PascalCase（如 `LayerManager`）
- 方法名：PascalCase（如 `GetLayerNames`）
- 私有字段：camelCase前缀下划线（如 `_layerCache`）
- 局部变量：camelCase（如 `layerName`）
- 常量：UPPER_SNAKE_CASE（如 `MAX_LAYER_COUNT`）

#### 结构优化
- 方法长度不超过50行
- 圈复杂度不超过10
- 提取重复代码为公共方法
- 消除魔法数字，使用常量

### 文档规范（新增）

#### XML注释要求
```csharp
/// <summary>
/// 获取指定名称的图层
/// </summary>
/// <param name="layerName">图层名称</param>
/// <returns>图层对象，如果不存在返回null</returns>
/// <exception cref="ArgumentException">图层名称为空时抛出</exception>
public LayerTableRecord GetLayer(string layerName)
{
    // 实现代码
}
```

#### 注释内容要求
- **summary**: 简要说明功能
- **param**: 每个参数的作用
- **returns**: 返回值说明
- **exception**: 可能抛出的异常
- **remarks**: 补充说明（如需要）

#### README编写
- 功能概述
- 使用方法
- 示例代码
- 注意事项

## 状态流转

在统一工作流中，码农君参与的状态：

```
assigned（妈妈分配任务）
    ↓
doing（码农君开发中）
    ↓
developed（开发完成，提交代码）
    ↓
testing（测试君验证）
    ↓

```

如果测试失败，回到 `doing` 重新开发。
