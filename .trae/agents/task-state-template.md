## 使用说明

### 创建任务时
1. 复制此模板
2. 填写任务基本信息
3. 设置初始状态为 `pending`
4. 规划任务步骤

### 任务进行中
1. 更新当前状态
2. 记录已完成步骤
3. 标记当前进行中的步骤
4. 记录协作切换

### 发生错误时
1. 更新状态为 `error`
2. 记录错误信息
3. 妈妈评估是否回滚

### 回滚时
1. 妈妈执行 `git reset --hard HEAD^`
2. 更新状态为 `rollback`
3. 记录回滚原因
4. 重新分配任务

### 任务完成时
1. 更新状态为 `done`
2. 确认所有产出物
3. 妈妈合并到dev分支
4. 归档此文件
