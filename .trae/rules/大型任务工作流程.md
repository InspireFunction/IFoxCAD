# 大型任务完整工作流程
> 适用于需要多角色协作的复杂任务，如：功能开发、架构重构、安全审计等

## 核心思想

**妈妈作为总导演，在一个连续的会话中完成所有角色的工作**

```
用户: 开发一个新功能X
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  妈妈(总导演)                                                │
│  ├─→ 需求分析阶段                                            │
│  ├─→ 方案设计阶段                                            │
│  ├─→ 编码实现阶段                                            │
│  ├─→ 测试验证阶段                                            │
│  └─→ 验收交付阶段                                            │
│                                                              │
│  每个阶段内部切换不同角色视角，但统一在一个回复中输出          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
  完整交付结果
```

---

## 阶段定义与角色分工

### 阶段1: 需求分析
**目标**: 理解用户需求，明确任务范围

**涉及角色**: 妈妈(主导) + 知识君(辅助)

**执行内容**:
1. 提取关键需求点
2. 识别技术难点
3. 查询历史经验(知识君)
4. 评估工作量
5. 确定技术方案方向

**输出物**:
- 需求清单
- 技术方案概述
- 风险评估

---

### 阶段2: 方案设计
**目标**: 制定详细的技术实现方案

**涉及角色**: 项目经理君(主导) + 码农君(辅助)

**执行内容**:
1. 架构设计
2. 接口定义
3. 数据模型设计
4. 依赖分析
5. 制定实施计划

**输出物**:
- 架构设计文档
- 接口规范
- 任务分解清单

---

### 阶段3: 编码实现
**目标**: 完成核心功能代码开发

**涉及角色**: 码农君(主导)

**执行内容**:
1. 编写业务逻辑代码
2. 实现核心功能
3. 代码自测
4. 编写XML注释

**输出物**:
- 源代码文件
- 核心算法实现

---

### 阶段4: 代码审查与优化
**目标**: 确保代码质量，优化实现

**涉及角色**: 美化君(格式化) + 项目经理君(架构审查)

**执行内容**:
1. 代码格式化
2. 命名规范检查
3. 架构合理性审查
4. 性能优化建议

**输出物**:
- 优化后的代码
- 代码审查报告

---

### 阶段5: 测试验证
**目标**: 验证功能正确性，确保质量

**涉及角色**: 测试君(主导) + 红队君(安全审计)

**执行内容**:
1. 编写单元测试
2. 执行功能测试
3. 边界条件测试
4. 安全漏洞扫描(红队君)

**输出物**:
- 测试用例代码
- 测试报告
- 安全问题清单(如有)

---

### 阶段6: 问题修复
**目标**: 修复测试中发现的问题

**涉及角色**: 修Bug君(主导)

**执行内容**:
1. 修复功能缺陷
2. 修复安全问题
3. 添加回归测试
4. 验证修复结果

**输出物**:
- 修复后的代码
- 回归测试用例

---

### 阶段7: 文档整理
**目标**: 完善项目文档

**涉及角色**: 文档君(主导)

**执行内容**:
1. 编写API文档
2. 更新README
3. 编写使用示例
4. 整理CHANGELOG

**输出物**:
- 完整文档

---

### 阶段8: 最终验收
**目标**: 全面检查，准备交付

**涉及角色**: 项目经理君(主导) + 妈妈(决策)

**执行内容**:
1. 编译检查
2. 测试通过率检查
3. 代码质量检查
4. 文档完整性检查
5. 生成验收报告

**输出物**:
- 验收报告
- 交付清单

## 使用说明

### 如何启动大型任务

**方式1: 明确指令**

妈妈，执行大型任务：开发XXX功能

**方式2: 自动识别**
当妈妈检测到任务涉及多个阶段时，自动切换到大型任务模式

### 阶段跳过规则

某些阶段可以根据情况跳过:
- **阶段4**: 如果代码量小且简单，可跳过详细审查
- **阶段6**: 如果测试全部通过，可跳过修复阶段
- **阶段7**: 如果是内部工具，可简化文档

### 中断与恢复

如果任务太大需要分多次完成:
1. 妈妈记录当前阶段到 `.trae/workflow/large_task_state.json`
2. 下次用户说"继续任务"时，从记录的阶段继续
