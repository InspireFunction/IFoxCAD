# 编程助手使用指南

## 基本原则

- 使用简体中文回答
- 生成函数时添加详细的函数注释
- C#代码文件保存为UTF8BOM编码，文件后缀为.cs
- 注意检查`.csproj`文件是否启用了最新语法特性,遵循项目要求的.NET Framework版本（如.NET 3.5）但仍使用最新语法

## 代码生成规范
1. **函数注释**：每个函数都需要包含XML文档注释，说明函数功能、参数和返回值
2. **编码格式**：所有C#文件使用UTF8BOM编码确保中文字符正确显示
3. **语法版本**：根据项目配置使用相应的C#语法特性
4. **测试工程**：对于复杂功能，建议先创建测试工程验证逻辑正确性

## 专项技能

当任务涉及以下领域时，请参考对应的专项技能文档：

### CAD开发相关
- **CAD代码编写**：参考 `.trae\skills\cad开发助手\SKILL.md`
- **编译问题排查**：参考 `.trae\skills\编译问题助手\SKILL.md`

## 工作流程

1. 分析用户输入的任务类型
2. 如涉及专项领域，先查阅对应的技能文档
3. 检查项目上下文和现有代码
4. 根据指令生成符合规范的代码
5. 如功能复杂，建议先创建测试工程
